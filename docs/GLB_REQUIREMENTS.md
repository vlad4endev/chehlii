# Требования к 3D-моделям (GLB) для лендинга casetop

Файл для дизайнеров и 3D-артистов. Готовая модель подключается в админке:
**Настройки → Мини-приложение → GLB URL**.

## Формат и вес

| Параметр | Требование |
|---|---|
| Формат | **GLB** (бинарный glTF 2.0). GLTF+BIN отдельно не принимаем. |
| Размер файла | **5–10 МБ** (ориентир). Больше 15 МБ — сжимать текстуры / LOD. |
| Полигоны | до **~100 000** треугольников |
| Текстуры | **PBR** (baseColor / metallicRoughness / normal / AO по необходимости) |
| Разрешение текстур | до **2048×2048** на карту |
| Центр модели | модель **центрирована** в начале координат (0,0,0), стоя на «полу» по Y |
| Сцена | **без камер и без источников света** в файле — освещение даёт `model-viewer` |

## Что должно быть в файле

1. Один основной меш (или небольшая иерархия), понятный масштаб под телефонный чехол.
2. Материалы PBR (`metallicRoughness` workflow).
3. UV-развёртка без сильных наложений на видимых гранях.
4. Встроенные текстуры (embedded) — один `.glb`, без внешних `.png`.

## Чего не должно быть

- Камер (`PerspectiveCamera` / `OrthographicCamera`)
- Светильников (`DirectionalLight`, `PointLight`, …)
- Анимаций скелета / морфов (пока не нужны)
- Скрытых helper-объектов, сетки пола, кубов-заглушек
- Проприетарных расширений, ломающих `model-viewer`

## Как проверить перед сдачей

1. Открыть в [gltf.report](https://gltf.report/) или Blender → File → Export → glTF 2.0 (.glb).
2. Полигоны ≤ 100k, текстуры ≤ 2048, вес в целевом диапазоне.
3. В сцене нет Camera / Light.
4. Origin в центре основания модели.
5. Проверить в Chrome с `<model-viewer src="…">` (auto-rotate + touch).

## Подключение в продукте

1. Загрузить `.glb` на доступный HTTPS (админка: `/admin/media` или CDN).
2. В **Настройки → Мини-приложение** указать URL в поле GLB.
3. Poster (превью до загрузки) = текущая hero-картинка.
4. На лендинге: auto-rotate, вращение пальцем, **без** zoom колёсиком; при ошибке/без GLB — обычное фото.
